# 🍹 Power BI Beverage Sales Dashboard
 
## Overview
 
This Power BI dashboard was developed to analyze beverage sales performance, profitability, and regional distribution.
 
## Business Objectives
 
- Monitor sales performance
- Evaluate profit margins
- Compare brand performance
- Analyze regional profitability
- Support data-driven decision-making
 
## Tools Used
 
- Power BI
- Power Query
- DAX
- Data Modeling
 
## Key KPIs
 
- Total Revenue
- Total Cost
- Total Profit
- Highest Sale
- Total Sales Volume
- Monthly Margin
 
## Dashboard Features
 
- Dynamic filtering by city
- Dynamic filtering by product category
- Year and month sales analysis
- Regional profit analysis
- Brand performance comparison
- Monthly margin tracking
